# Анализ HTTP-запроса

## Выбранный запрос

- URL: https://github.com/
- Метод: GET
- Статус ответа: 200 OK
- Content-Type: text/html; charset=utf-8
- Проверка выполнена 21 октября 2026 года в 14:53:07 МСК.

## Источник данных

Для уточнения отчёта выполнен один повторный GET-запрос без авторизации через PowerShell Invoke-WebRequest. Три заголовка запроса ниже были явно заданы при отправке; все заголовки ответа взяты из ответа на этот же запрос.

Это фактические значения HTTP-клиента, а не снимок DevTools. Проверку именно через DevTools → Network, которую запросил преподаватель, ещё нужно выполнить. Значения прежнего браузерного запроса не восстанавливались по памяти.

## Request Headers

| Заголовок | Отправленное значение | Назначение |
| --- | --- | --- |
| Accept | `text/html` | Клиент ожидает HTML. |
| Accept-Language | `ru-RU,ru;q=0.9,en;q=0.8` | Предпочтительные языки; q задаёт их приоритет. |
| User-Agent | `Lab01-Header-Check/1.0` | Название учебного HTTP-клиента, заданное для проверки. |

## Response Headers

| Заголовок | Полученное значение | Назначение |
| --- | --- | --- |
| Date | `Wed, 21 Oct 2026 11:52:58 GMT` | Время ответа по данным сервера. |
| Content-Type | `text/html; charset=utf-8` | Ответ содержит HTML в UTF-8. |
| Cache-Control | `max-age=0, private, must-revalidate` | Ответ предназначен для частного кеша; перед повторным использованием требуется проверка. |
| Strict-Transport-Security | `max-age=31536000; includeSubdomains; preload` | Политика HSTS предписывает HTTPS на год, включая поддомены. |
| X-Content-Type-Options | `nosniff` | Запрещает MIME-sniffing в предусмотренных браузером случаях. |
| X-Frame-Options | `deny` | Запрещает отображение страницы внутри фрейма. |
| Server | `github.com` | Значение, которым сервер обозначил себя в ответе. |

Cookie, Set-Cookie и Authorization в отчёт не включены. При повторном запросе Date и другие значения могут отличаться.

## Краткий анализ

Клиент отправил GET-запрос к главной странице GitHub. Сервер вернул статус 200 OK и HTML-документ в UTF-8. Заголовки описывают тип содержимого, правила кеширования и ограничения безопасности. В таблицах приведены значения одного конкретного запроса и его ответа.
