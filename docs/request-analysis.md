Анализ HTTP-запроса
URL запроса
https://github.com/
HTTP Method
GET
Status Code
200 OK
Content-Type
text/html; charset=utf-8
Request Headers
- Accept — указывает, какие типы данных браузер может принять.
- Accept-Language — указывает предпочитаемый язык ответа.
- User-Agent — содержит информацию о браузере и операционной системе.
- Cookie — передаёт сохранённые данные сессии сайта.
Response Headers
- Content-Type — указывает тип возвращаемого содержимого: HTML.
- Content-Security-Policy — задаёт правила безопасности для страницы.
- Server — содержит информацию о серверной инфраструктуре.
- Strict-Transport-Security — заставляет браузер использовать HTTPS.
- X-Content-Type-Options — запрещает браузеру изменять определение типа содержимого.
Краткий анализ
Браузер отправил серверу GitHub GET-запрос по адресу
https://github.com/. Сервер успешно обработал запрос и вернул
статус 200 OK. В ответ браузер получил HTML-документ,
который используется для отображения главной страницы GitHub.
