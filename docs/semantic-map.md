## section, article и div
section объединяет отдельную тему с заголовком. Карточки походов — article, потому что каждая содержит самостоятельную информацию: название, даты, сложность и продолжительность. Короткие преимущества не оформлены как article: они являются частями общего списка. Отзыв представлен как цитата с подписью, поэтому выбран figure с blockquote. Имя автора не размечено cite: это не название произведения.

div пока не нужен: нет необходимости добавлять контейнеры исключительно ради будущего расположения блоков. Прямоугольники и Frames из макета не переносятся автоматически.

## Заголовки и длинный текст
Один h1 — «Природный парк Ергаки». Основные разделы имеют h2, названия походов и пунктов преимуществ — h3.

Для проверки устойчивости «Первое знакомство» заменено на «Первое знакомство с Ергаками: лёгкий поход к озёрам и скалам», примерно втрое длиннее. В обоих вариантах это один h3 внутри того же article; дополнительных контейнеров нет. Перенос текста проверен в узком окне браузера; результаты — в checks.md.

## Изображения
В HTML используются пять содержательных JPEG из SVG: первый экран, панорама и три фотографии походов. Каждый alt описывает видимое содержимое. Не утверждается, что изображения документально подтверждают географическое место. Даты на карточках уже впечены в JPEG, но дополнительно доступны текстом в time.

Четыре декоративных значка, два аватара и фон формы тоже извлечены и сохранены для будущей стилизации, но пока не используются. Об источнике файлов см. image-sources.md.

## Ссылки и форма
«Заказать тур» — ссылка к форме. «Выбрать поход» тоже ссылка: переходит к форме, а небольшой скрипт дополнительно выбирает маршрут в select. Без скрипта переход сохраняется.

«Оставить заявку» — button type="submit". Имя имеет type="text", телефон — type="tel". У обоих есть required и соответствующий autocomplete. label связан с полем через for и id; name определяет имя данных. Поле выбора похода добавлено для связи карточек с заявкой, значение по умолчанию — «Помогите выбрать».

Нативная проверка required проверяет наличие текста, но не существование номера телефона. Скрипт отменяет отправку через preventDefault и показывает учебный результат. Кнопка включается после подключения обработчика; при отключённом JavaScript данные не отправляются кнопкой. role="status" нужен для объявления динамического результата, aria-describedby связывает форму с пояснением.

Две области nav получили разные доступные названия. Ссылка «Контакты» ведёт к форме связи: других контактных данных в SVG нет. «Узнать больше» ведёт к «Что вас ждёт». Для «Все походы», «Все отзывы», социальных и юридических ссылок в макете нет целевых страниц, поэтому фиктивные ссылки не добавлены.
