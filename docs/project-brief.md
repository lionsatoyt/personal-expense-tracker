# Вершина

## Продукт

«Вершина» — учебный туристический сайт для выбора и бронирования походов в природном парке Ергаки. Проект разрабатывается по макету `ergaki-figma-v2.svg`.

## Проблема

Пользователям необходимо удобно находить информацию о походах, сравнивать маршруты по сложности, продолжительности и стоимости.

## Пользователь

Люди, которые интересуются туризмом и хотят выбрать подходящий поход для отдыха на природе.

## Основной сценарий

Пользователь открывает сайт, знакомится с маршрутами, выбирает подходящий поход и заполняет форму заявки.

## Цель проекта

Создать удобный туристический сайт с информацией о походах, маршрутах, датах и возможностью записи.

## Ограничения

На текущем этапе реализуется HTML-структура сайта. CSS-оформление и дополнительные функции будут добавлены в следующих практических работах.

Форма заявки работает в учебном режиме без отправки данных на сервер.
