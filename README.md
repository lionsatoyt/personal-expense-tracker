# Вершина — практика №2

Учебный туристический сайт о походах в природном парке Ергаки. Тема изменена с учёта расходов на «Вершину»; работа продолжается в том же репозитории.

Автор: Бободжанов Султонджон Джамшедович.

## Запуск

Скачайте проект и откройте `index.html` в браузере. Установка зависимостей и сервер не нужны. При наличии Python можно запустить `python -m http.server 8000` из папки проекта и открыть http://localhost:8000/.

## Что реализовано

- Базовый HTML-документ на русском языке, header, nav, main и footer.
- Информация о парке, три самостоятельные карточки походов, особенности поездки и примеры отзывов.
- Пять содержательных изображений с alt из макета `ergaki-figma-v2.svg`.
- Форма с label, id, name, required и autocomplete; выбор похода из карточки переносится в форму.
- Длинный заголовок первой карточки для проверки устойчивости структуры.

Стек: HTML, одно правило CSS для размера изображений и небольшой учебный скрипт JavaScript. Точная стилизация будет в следующих практиках. Форма проверяет обязательные поля, но не отправляет заявку на сервер. Для проверки используйте вымышленные данные.

## Перед защитой

Откройте страницу, повторите проверку из `docs/checks.md` и просмотрите DOM во вкладке Elements в DevTools. Нужно уметь объяснить выбор section/article, уровни заголовков, alt, связь label с полем, назначение name и отличие ссылки от submit-кнопки. `type="tel"` не проверяет существование телефона.
