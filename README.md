# Вершина

## Идея проекта

«Вершина» — учебный туристический сайт для организации походов в природном парке Ергаки.

Сайт предназначен для просмотра маршрутов, дат походов и заполнения формы заявки.

## Планируемый стек

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Запуск

Открыть файл index.html в браузере.

## Что реализовано

- Семантическая структура HTML.
- Карточки туристических маршрутов.
- Изображения и отзывы.
- Форма записи на поход.
