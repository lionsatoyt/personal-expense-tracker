Название проекта: Personal Expense Tracker

Идея проекта:
Personal Expense Tracker — учебный веб-проект для учета личных расходов. 
Приложение предназначено для добавления и просмотра расходов пользователя, 
а также для получения общей информации о структуре личных трат. 
В дальнейшем проект планируется расширить возможностью анализа расходов.

Планируемый стек:
- HTML
- CSS
- JavaScript
- PHP
- MySQL

Запуск:
На текущем этапе проект находится в разработке. 
Инструкция по запуску будет дополнена по мере разработки проекта.
