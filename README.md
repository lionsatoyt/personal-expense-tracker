# Название проекта: Вершина

## Идея проекта
«Вершина» — учебный веб-проект туристического сайта для организации походов в Ергаки.

Сайт предназначен для просмотра доступных походов, ознакомления с маршрутами, датами и стоимостью, а также для записи на выбранный поход.

В дальнейшем планируется добавить отзывы туристов, личный кабинет и онлайн-бронирование.

## Планируемый стек

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Запуск

На текущем этапе проект находится в разработке. Инструкция по запуску будет дополнена по мере разработки проекта.
